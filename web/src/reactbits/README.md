# React Bits kaynakları

DavidHDev/react-bits, sabit kaynak commit: `7e0220aac5804bb55696868de6b590ffddc14f35`.
https://github.com/DavidHDev/react-bits/tree/7e0220aac5804bb55696868de6b590ffddc14f35/src/ts-default

TS + CSS sürümleri doğrudan kaynak depodan alınmıştır. Lisans LICENSE.md içindedir. Bileşenler JARVIS uygulamasının parçası olarak kullanılır.

Yerel uyarlamalar: Orb gerçek ses RMS referansını ve uygulama durumunu okur; cyan shader renkleri, sınırlı DPR ve mobil kare hızı. GL bileşenleri gizli sekmede render etmez; Particles temizlenirken GPU bağlamı bırakılır. Orb ve Aurora ResizeObserver ile panel boyutlarına uyum sağlar.

Split Text için ek GSAP SplitText eklentisi yerine Decrypted Text ve Blur Text seçildi. Lightning yerine Orb enerji shader'ı kullanılır.
